# ThermoTouch UFH

Monitor and control ETOP / Thermogroup **ThermoTouch** underfloor-heating thermostats from
Home Assistant, over the ETOP cloud (no local redirect once set up). Climate, towel rail,
room temperature and heating status.

You need the thermostat's MAC and token (and a command template for control), captured once
with the companion `thermotouch-bridge`. See the README.
